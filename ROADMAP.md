# Roadmap — Chess Opening Trainer

| ID | Phase | Goal | Acceptance Criteria | Status | Depends On |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `1.1-scaffold` | Phase 1 | Responsive 1/2/3-column layout shell, GitHub Pages Actions pipeline (`dist/`), clean console | Live GitHub Pages URL loads, responsive across mobile/split-pane/desktop, 0 console errors | Done | — |
| `1.2-parser` | Phase 1 | Pure Markdown parser + `chess.js` move validator + automated unit tests | Passes all required happy & broken-path tests; `queens-gambit.md` parses with 0 errors | Done | `1.1-scaffold` |
| `1.3-board` | Phase 1 | Interactive CSS Grid chessboard with bundled Staunton SVGs, fluid sizing, click-to-move, legal/capture highlights, move history, and keyboard accessibility | Click piece highlights legal moves (green) & captures (red); illegal clicks ignored; board updates, history updates, turn flips; works on mobile tap | Done | `1.1-scaffold`, `1.2-parser` |
| `2.1-manifest` | Phase 2 | Auto-generate `manifest.json` via GitHub Actions on `lines/**` changes | Pushing a `.md` file updates `manifest.json` with `[skip ci]` | Done | `1.2-parser` |
| `2.2-library` | Phase 2 | Fetch `manifest.json` (`no-store`) and load multiple openings with error banner | 3+ sample openings load and display; broken files show clear error banner | Done | `2.1-manifest` |
| `3.1-drill` | Phase 3 | Variation drill state machine (`IDLE`, `USER_TURN`, `OPPONENT_TURN`, `VARIATION_COMPLETE`) | Drill completes as White & Black; board locked during opponent reply | Done | `1.2-parser`, `1.3-board` |
| `3.2-controls` | Phase 3 | Coaching controls (Hint, Reset, Auto-Loop, Practice All) + mistakes/progress | Hint highlights source + target; Practice All cycles `1..N` | Done | `3.1-drill` |
| `3.3-persistence` | Phase 3 | Persist `lastOpening`, `lastVariation`, `mistakesByVariation` in `localStorage` | Page refresh restores active variation and mistake counts | Done | `3.2-controls` |
| `3.4-practice-test-modes` | Phase 3 | Practice vs Test session modes (`Practice` shows live move direction arrow + SAN cue; `Test` preserves unassisted drill with on-demand Hint) | Segmented mode switcher above board toggles Practice and Test cleanly across White/Black orientations | Done | `3.1-drill`, `3.2-controls` |
| `4.1-ux-sprint-1` | UX Sprint 1 | Core Loop UX: Design tokens (`tokens.css`), 48px TurnBanner with Correct!/Wrong feedback, non-truncated 3-line variation list + search, ProgressHeader with Accuracy %, FEN moved into `...` board menu | Practice/Test TurnBanner pulses green on Correct! (600ms auto-advance) & shakes red on Wrong; variation names never truncate; Accuracy % updates live; FEN tucked into `...` menu | Done | `3.4-practice-test-modes` |
| `4.2-ux-sprint-2` | UX Sprint 2 | Trainer Experience: `New`/`Learning`/`Mastered` status badges & persistence, structured `Idea`/`Plan`/`Watch Out` Study Notes with Read more, CompletionModal (`Line Complete!`), Practice vs Test tooltips/labels & hint gating | Fresh lines start `New`, flipping to `Mastered` after two ≥80% completions; every line shows Idea+Plan; CompletionModal appears immediately with Practice Again / Next Line / Back to Library; Test disables hints & arrows | Done | `4.1-ux-sprint-1` |
